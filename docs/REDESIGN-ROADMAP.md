# Portfolio redesign roadmap

Phase 1 introduced the static generator, unified data, case studies and core tests. Phase 2 retains those foundations and rebuilds the presentation around the person, breadth of experience and authentic product media.

1. Reproduce the baseline from PR #2 and do a content and imagery audit.
2. Reconcile the career record and training, refresh the CV and current product evidence.
3. Introduce typography-led navigation and distinct product presentation, with individual case content and accessible controls.
4. Review the actual site independently on desktop and mobile. Fix candidate clarity, mobile wayfinding, keyboard focus, video loading, CV reading order and layout collisions.
5. Verify the generated production bundle and publish it through GitHub Pages.

The committed workflow keeps production publishing reproducible. The source, tests and review notes remain available in the repository for maintainers.
