Marco Ladeira

About

I'm Marco Ladeira, a software engineer in Dublin. At work I build enterprise AI for financial-services compliance at Fenergo. In my own time I build products from the ground up — at the moment, an AI coding workspace called Vesta and a puzzle game called ONE Oddlings.

How I got here

I studied at Dundalk Institute of Technology from 2021, first for a BSc in Computing and then an honours degree in Software Development, which I finished in 2025. I worked hospitality shifts through the first years of college, took on freelance development for a start-up in my final year, and was the sole developer of the patient app in our final-year smart pill-dispenser project.

I joined Fenergo as a Graduate Software Engineer in September 2025, on event-driven backend work for client lifecycle management software. A few months later I was selected for the company's first AI initiative, and I've since helped build an enterprise AI application from scratch to a beta release as one of a three-person engineering team. Along the way I was promoted to Associate Software Engineer.

How I work

Show the working
If a system makes a claim — a cost, a forecast, a fix — it should be able to show where the claim comes from. I'd rather label an estimate than oversell it.
Design the failure path
Stop buttons that stop, fallbacks that keep a demo alive, retries that can't double-charge. The unhappy path deserves as much care as the happy one.
Test at more than one layer
Unit tests, end-to-end tests, visual snapshots and — where content is generated — an independent checker that shares no code with the generator.
Care about the last 10%
Copy, motion, keyboard support, reduced motion and the first ten seconds of use are where people decide whether to trust software.
